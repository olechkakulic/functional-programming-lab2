## Ключевые элементы реализации  

Структура множества представлена как Clojure-map:

- `:buckets` — вектор бакетов (каждый бакет — вектор элементов множества);  
- `:capacity` — количество бакетов (фиксированный размер).  

Для размещения элемента используется стандартный `hash` и остаток от деления на `capacity`:

```clojure
(defn- bucket-index [capacity e]
  (mod (hash e) capacity))
```

Все операции возвращают новый экземпляр структуры, исходный не изменяется.

Основные функции модуля sc-set:

empty
Создаёт пустое множество.

add
Добавляет элемент в множество. Повторное добавление того же элемента не меняет структуру (идемпотентность).

remove
Удаляет элемент из множества (если элемента нет, структура не изменяется).

contains-element
Проверяет принадлежность элемента множеству, возвращает true/false.

filter
Оставляет только те элементы, для которых предикат pred возвращает истину:

c
Копировать код
(filter pred set)
map
Отображает элементы множества через функцию f. Результат — новое множество, возможные дубликаты удаляются:

clojure
Копировать код
(map f set)
fold
Левая свёртка по элементам множества:

clojure
Копировать код
(fold f init set) ; f: acc elem -> acc
fold-back
Правая свёртка по элементам множества:

clojure
Копировать код
(fold-back f init set) ; f: elem acc -> acc
combine
Операция моноида — объединение множеств (union).
Все элементы из обоих множеств попадают в результат.

equals
Сравнивает два множества через их API, проверяя, что:

каждое множество является подмножеством другого;

сравнение происходит без обращения к внутреннему представлению и без сортировки списков.

Моноид
Введена структура моноида на множестве:

нейтральный элемент — пустое множество empty;

бинарная операция — combine, реализующая объединение:

c
Копировать код
(combine a b) ; a ∪ b
Проверены свойства:

левый и правый нейтральный элемент:
combine empty s == s и combine s empty == s;

ассоциативность:
combine a (combine b c) == combine (combine a b) c.

Тестирование
Unit-testing
В модуле unit (каталог test) реализованы юнит-тесты, покрывающие:

добавление и проверку принадлежности (add, contains-element);

удаление (remove);

фильтрацию (filter);

отображение (map);

свёртку (fold);

объединение (combine) как union;

сравнение множеств (equals) и свойства нейтрального элемента.

Property-based testing
В модуле property-tests используются clojure.test.check:

Проверяются свойства:

add-then-contains: после add элемент обязательно содержится в множестве;

remove-behaviour: после remove элемента нет в множестве, а принадлежность остальных элементов не меняется;

моноидальные свойства combine:

нейтральный элемент (empty) слева и справа;

ассоциативность комбинирования множеств;

композиция map:

c
Копировать код
(map f (map g s)) == (map (comp f g) s)
по сравнению множеств через equals.
